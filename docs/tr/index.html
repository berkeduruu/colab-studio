kurmadan önce

Ücretsiz Colab sürümü çalışır mı?

Hayır. Ücretsiz sürümde L4 GPU yok. Colab compute unit gerekir: Colab Pro, Pro+ ya da kullandıkça öde.

T4 ya da A100 kullanabilir miyim?

Hayır. İş akışları, VRAM bütçeleri ve süre tahminleri L4’te ölçüldü; desteklenen tek GPU L4.

Telefonumdan açabilir miyim?

Evet: SSH tüneliyle, güvenilir bir ağda IP ile ya da kendi alan adında nginx, HTTPS ve parolayla. Bunu deploy/setup-nginx.sh kurar.

Sonuçlarım nerede durur?

Kendi makinende. Sonuçlar GPU’dan geri kopyalanır ve GPU kapandıktan sonra da durur. 30 günden eski sohbetler kendiliğinden silinir.

Claude Code kullanabilir mi?

Evet. mcp klasöründe bir MCP sunucusu var; Claude Code ya da Claude Desktop GPU’yu açabilir, medya üretebilir, işleri bekleyip sonuçlara bakabilir.

Google mı yaptı?

Hayır. Colab Stüdyo, AGPL-3.0 lisanslı bağımsız, açık kaynaklı bir projedir. Google’ın resmi Colab CLI’ını kullanır.

nasıl kurulur?

$ git clone https://github.com/berkeduruu/colab-studio.git
$ cd colab-studio
$ ./install.sh && ./run.sh

Kurulum seni Colab’a bağlar; sonra 127.0.0.1:8190 adresini aç ve bir istem gönder. Konteyner mi istiyorsun? Docker kurulumuna bak.
